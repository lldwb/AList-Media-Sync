# 环境变量清单

> 本文档是 AList-Media-Sync 环境变量的**单一权威来源**（SSOT）。
> 其他文档（如 `06-运维部署.md`、`故障排查与日志.md`）仅引用本文档，不重复全量配置表。
> 配置源码：`src/main/resources/application.yaml`、`Dockerfile`、`docker-compose.yml`、`.env`。

## 配置机制

AList-Media-Sync 采用 Spring Boot Relaxed Binding（松散绑定）机制，所有 `app.*` 命名空间的配置属性均可通过大写下划线格式的环境变量覆盖。映射规则示例：

- `app.data-dir` → `DATA_DIR`
- `app.auth.password` → `APP_AUTH_PASSWORD`
- `app.transcode.max-concurrent-transcode` → `TRANSCODE_MAX_CONCURRENT`

非 `app.*` 命名空间的变量（如 `ALIST_BASE_URL`、`JAVA_OPTS`）直接由代码或 Docker Compose 读取，不经过 Relaxed Binding。

## 一、app.* 命名空间映射变量

下表列出 12 个通过 Relaxed Binding 映射到 `app.*` 配置属性的环境变量。

| 配置属性 | 环境变量 | 默认值 | 是否必填 | 说明 | 示例 |
|---|---|---|---|---|---|
| `app.data-dir` | `DATA_DIR` | `./data`（本地）<br>`/app/data`（Docker） | 否 | 数据库文件存储目录。H2 文件模式数据库文件位于此目录下。Docker 场景由 `docker-compose.yml` 固定为 `/app/data`。 | `DATA_DIR=/app/data` |
| `app.auth.password` | `APP_AUTH_PASSWORD` | `admin123` | **生产必填** | 管理后台登录密码。仅支持明文，启动时自动 BCrypt 加密存入内存。**敏感，日志与诊断包脱敏。** 生产环境必须替换默认值。 | `APP_AUTH_PASSWORD=MyStr0ng!Pass` |
| `app.transcode.temp-suffix` | `TRANSCODE_TEMP_SUFFIX` | `.tmp` | 否 | 转码临时文件后缀。不以点号开头时自动补充。合法字符：字母、数字、点号、下划线、连字符。 | `TRANSCODE_TEMP_SUFFIX=.tmp` |
| `app.transcode.temp-dir` | `TRANSCODE_TEMP_DIR` | `${java.io.tmpdir}/alist-media-sync/transcode` | 否 | 转码临时文件存储目录。Docker 场景建议挂载独立卷指向此路径。 | `TRANSCODE_TEMP_DIR=/app/transcode-tmp` |
| `app.transcode.max-concurrent-transcode` | `TRANSCODE_MAX_CONCURRENT` | `32` | 否 | 最大并发转码任务数。与 `JAVA_OPTS` 内存上限联动：每个转码任务启动独立 FFmpeg 进程，过高会导致 OOM。参见 [06-运维部署.md](../06-运维部署.md#转码并发与内存关系)。 | `TRANSCODE_MAX_CONCURRENT=16` |
| `app.websocket.max-connections` | `APP_WEBSOCKET_MAX_CONNECTIONS` | `50` | 否 | WebSocket 最大并发连接数。超过上限时拒绝新连接并返回 HTTP 429。 | `APP_WEBSOCKET_MAX_CONNECTIONS=100` |
| `app.retry.max-auto-retries` | `APP_RETRY_MAX_AUTO_RETRIES` | `3` | 否 | 最大自动重试次数。设为 `0` 禁用自动重试。初始间隔 1 秒，最大间隔 60 秒，指数退避。 | `APP_RETRY_MAX_AUTO_RETRIES=5` |
| `app.server-address` | `SERVER_ADDRESS` | 自动探测 | 否 | 应用对外暴露地址（含协议与端口），用于 Webhook 回调 URL 拼接。Docker 环境由 `ServerAddressLogger` 自动探测。 | `SERVER_ADDRESS=https://ams.example.com` |
| `springdoc.api-docs.enabled` | `SPRINGDOC_API_DOCS_ENABLED` | `true` | 否 | 是否启用 OpenAPI API 文档端点（`/v3/api-docs`）。生产环境建议设为 `false`。 | `SPRINGDOC_API_DOCS_ENABLED=false` |
| `springdoc.swagger-ui.enabled` | `SPRINGDOC_SWAGGER_UI_ENABLED` | `true` | 否 | 是否启用 Swagger UI（`/swagger-ui.html`）。生产环境建议设为 `false`。 | `SPRINGDOC_SWAGGER_UI_ENABLED=false` |
| `app.mcp.enabled` | `MCP_ENABLED` | `false` | 否 | MCP 服务器总开关，默认禁用（FR-012）。为 `true` 且 `MCP_TOKEN` 非空时 `/mcp` 端点才提供服务；`true` 且令牌为空时启动报错拒绝启用。 | `MCP_ENABLED=true` |
| `app.mcp.token` | `MCP_TOKEN` | 空 | 启用 MCP 时必填 | MCP 专用访问令牌（Bearer Token），与 Web 管理 Basic Auth 凭据隔离。**敏感，日志与诊断包脱敏；工具返回与日志 MUST NOT 回显明文。** 建议 32+ 字符随机串。 | `MCP_TOKEN=$(openssl rand -hex 32)` |

## 二、非 app.* 环境变量

下表列出 9 个不经过 Relaxed Binding 的环境变量，由代码、Dockerfile 或 Docker Compose 直接读取。

| 环境变量 | 默认值 | 是否必填 | 说明 | 示例 |
|---|---|---|---|---|
| `SERVER_PORT` | `8080` | 否 | 容器内 HTTP 服务端口。由 `server.port` 配置项读取。 | `SERVER_PORT=8080` |
| `PORT` | `8080` | 否 | Docker Compose 主机端口映射。仅 `docker-compose.yml` 使用，不注入应用进程。 | `PORT=8080` |
| `ALIST_BASE_URL` | 无 | **必填** | AList 服务器地址。应用启动时校验，缺失或不可达将导致存储引擎初始化失败。 | `ALIST_BASE_URL=https://alist.example.com` |
| `ALIST_TOKEN` | 无 | **必填** | AList API 认证令牌，从 AList 管理后台获取。**敏感，日志与诊断包脱敏。** | `ALIST_TOKEN=als_xxxxxxxx` |
| `ALIST_CRYPTO_KEY` | 随机生成 | **生产必设** | AES-256 加密密钥（Base64 编码 32 字节）。用于数据库敏感字段加密/解密。缺失时每次启动随机生成，导致已加密数据无法解密。生成方法：`openssl rand -base64 32`。**敏感，日志与诊断包脱敏。** | `ALIST_CRYPTO_KEY="nXC2xph4AH1yNlt1dCE0DK0ecdIS5BEFF6BZ1KvSyV8="` |
| `LOGGING_LEVEL` | `INFO` | 否 | 全局日志级别。取值：`TRACE`、`DEBUG`、`INFO`、`WARN`、`ERROR`、`OFF`。业务包 `top.lldwb.alistmediasync` 跟随此值。详见 [故障排查与日志.md](故障排查与日志.md#日志级别调整)。 | `LOGGING_LEVEL=WARN` |
| `LOG_PATH` | `./logs` | 否 | 日志输出目录。Docker 场景由 `docker-compose.yml` 固定为 `/app/logs`。 | `LOG_PATH=/app/logs` |
| `JAVA_OPTS` | `-Xms128m -Xmx256m` | 否 | JVM 运行参数。Docker Compose 通过此变量注入堆内存配置。与 `TRANSCODE_MAX_CONCURRENT` 联动调整。参见 [06-运维部署.md](../06-运维部署.md#转码并发与内存关系)。 | `JAVA_OPTS="-Xms256m -Xmx512m"` |
| `DOCKER_CONTAINER` | `true`（Dockerfile 内置） | 否 | 标记容器环境，供 `ServerAddressLogger` 检测使用。Dockerfile 中通过 `ENV DOCKER_CONTAINER=true` 设置，无需手动配置。 | — |

## 三、敏感项标记

以下环境变量包含敏感信息，在日志输出与诊断包中均会被脱敏处理（替换为 `***REDACTED***`）：

| 环境变量 | 脱敏位置 | 脱敏方式 |
|---|---|---|
| `ALIST_TOKEN` | `diagnose.sh` 环境变量收集、日志输出 | `awk` 正则匹配 `token` 关键词 |
| `ALIST_CRYPTO_KEY` | `diagnose.sh` 环境变量收集 | `awk` 正则匹配 `cryptokey`/`crypto_key` 关键词 |
| `APP_AUTH_PASSWORD` | `diagnose.sh` 环境变量收集、日志输出 | `awk` 正则匹配 `password` 关键词 |
| `MCP_TOKEN` | `diagnose.sh` 环境变量收集、MCP 工具调用日志 | `awk` 正则匹配 `token` 关键词；MCP 工具响应 MUST NOT 回显明文（FR-011） |

> 脱敏实现参见 `scripts/diagnose.sh` 第 92-97 行（日志文件级脱敏）和第 121-128 行（环境变量级脱敏）。

## 四、生产环境建议

| 配置项 | 建议值 | 原因 |
|---|---|---|
| `ALIST_CRYPTO_KEY` | 必须设置，使用 `openssl rand -base64 32` 生成 | 缺失时每次重启生成随机密钥，已加密的数据库字段（如 AList Token）将永久不可解密 |
| `APP_AUTH_PASSWORD` | 避免默认值 `admin123`，使用强密码 | 默认密码可被公开文档查询到，存在未授权访问风险 |
| `MCP_TOKEN`（启用 MCP 时） | 32+ 字符随机串 | MCP 端点唯一认证凭据，弱令牌会被暴力破解；泄漏后修改并重启即可立即失效旧令牌 |
| `LOGGING_LEVEL` | `WARN` | 生产环境应减少日志量。业务包 `top.lldwb.alistmediasync` 在 `application.yaml` 中跟随全局级别，设置为 `WARN` 后仅 WARN 及以上日志输出 |
| `SPRINGDOC_API_DOCS_ENABLED` | `false` | 禁用 API 文档端点，避免未认证访问暴露 API 结构 |
| `SPRINGDOC_SWAGGER_UI_ENABLED` | `false` | 禁用 Swagger UI，同上 |
| `JAVA_OPTS` | 根据 `TRANSCODE_MAX_CONCURRENT` 调整 | 默认 `-Xmx256m` 仅支持轻量场景。转码并发越高，FFmpeg 子进程越多，需要更大的堆外内存上限。建议 `TRANSCODE_MAX_CONCURRENT=16` 时至少 `-Xmx512m` |
