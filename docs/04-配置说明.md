# 配置说明

> **本文件为配置说明的单一权威来源（SSOT）。**
> 代码层 SSOT 为 `src/main/java/top/lldwb/alistmediasync/common/config/AppProperties.java`（`@ConfigurationProperties(prefix = "app")`）；
> 运行时默认值定义于 `src/main/resources/application.yaml` 的 `app:` 命名空间。
> 其他文档（如 `06-运维部署.md`、`docs/operations/环境变量清单.md`）仅引用本文档，不重复全量配置表。

## 1. Spring Boot Relaxed Binding 机制

AList-Media-Sync 采用 Spring Boot Relaxed Binding（松散绑定）机制，将 `application.yaml` 中的 `app.*` 配置属性与 `AppProperties.java` 的字段绑定，并支持通过环境变量覆盖。映射规则如下：

| 配置格式 | 示例 | 说明 |
|---|---|---|
| kebab-case（yaml / 命令行参数） | `app.data-dir` | `application.yaml` 与命令行参数使用的格式 |
| camelCase（Java 字段） | `dataDir` | `AppProperties.java` 字段名，由 Spring 自动映射 |
| SCREAMING_SNAKE_CASE（环境变量） | `DATA_DIR` | 环境变量格式，下划线对应 kebab-case 中的连字符 |

**映射示例**：

| yaml 配置路径 | 环境变量 | AppProperties 字段 |
|---|---|---|
| `app.data-dir` | `DATA_DIR` | `AppProperties.dataDir` |
| `app.auth.password` | `APP_AUTH_PASSWORD` | `AppProperties.auth.password` |
| `app.transcode.max-concurrent-transcode` | `TRANSCODE_MAX_CONCURRENT` | `AppProperties.transcode.maxConcurrentTranscode` |
| `app.websocket.max-connections` | `APP_WEBSOCKET_MAX_CONNECTIONS` | `AppProperties.websocket.maxConnections` |

> 嵌套属性的环境变量映射规则：将完整路径中的连字符替换为下划线，全部转为大写。例如 `app.retry.initial-interval` → `APP_RETRY_INITIAL_INTERVAL`。

## 2. 三级配置优先级

同一配置项的多个来源按以下优先级从高到低覆盖：

```
命令行参数  >  环境变量  >  application.yaml  >  AppProperties.java 字段默认值
```

| 优先级 | 来源 | 示例 |
|---|---|---|
| 1（最高） | 命令行参数 | `--app.data-dir=/custom/data` |
| 2 | 环境变量 | `DATA_DIR=/custom/data` |
| 3 | `application.yaml` | `app.data-dir: ./data` |
| 4（最低） | `AppProperties.java` 字段默认值 | `private String dataDir = "/app/data";` |

> **注意**：`application.yaml` 中已通过 `${ENV_VAR:default}` 语法将环境变量与 yaml 默认值合并（如 `data-dir: ${DATA_DIR:./data}`），因此环境变量优先级天然高于 yaml 默认值。命令行参数由 Spring Boot 框架在最外层覆盖。

## 3. app.* 配置项完整清单

以下从 `AppProperties.java` 字段定义与 `application.yaml` 的 `app:` 命名空间抽取，共 **19 项**，分基础、认证、转码、运行时四组。

| 配置路径 | 环境变量 | 默认值 | 约束 | 说明 |
|---|---|---|---|---|

| `app.name` | `APP_NAME` | `AList-Media-Sync` | — | 应用名称，用于启动横幅与日志标识。yaml 中直接定义，未绑定到 `AppProperties` 字段。 |
| `app.version` | `APP_VERSION` | `0.0.1-SNAPSHOT` | — | 应用版本号，用于启动横幅与 OpenAPI 文档版本。yaml 中直接定义，未绑定到 `AppProperties` 字段。 |
| `app.retention-days` | `APP_RETENTION_DAYS` | `30` | `@Min(1)` | 历史记录保留天数。超过此天数的 `TaskExecution` 和 `WebhookEvent` 将被清理。 |
| `app.server-address` | `SERVER_ADDRESS` | 自动探测请求 origin | — | 应用对外暴露地址（含协议与端口），用于 Webhook 回调 URL 拼接。未配置时使用请求 origin，Docker 环境由 `ServerAddressLogger` 自动探测。 |

## 5. SpringDoc OpenAPI 配置

`springdoc.*` 命名空间配置由 SpringDoc OpenAPI 库读取，用于控制 API 文档端点的行为。共 6 项配置：

| 配置路径 | 环境变量 | 默认值 | 说明 |
|---|---|---|---|
| `springdoc.api-docs.path` | — | `/v3/api-docs` | OpenAPI JSON 文档端点路径。 |
| `springdoc.api-docs.enabled` | `SPRINGDOC_API_DOCS_ENABLED` | `true` | 是否启用 API 文档端点。生产环境建议设为 `false`，避免未认证访问暴露 API 结构。 |
| `springdoc.swagger-ui.path` | — | `/swagger-ui.html` | Swagger UI 界面路径。 |
| `springdoc.swagger-ui.enabled` | `SPRINGDOC_SWAGGER_UI_ENABLED` | `true` | 是否启用 Swagger UI。生产环境建议设为 `false`。 |
| `springdoc.packages-to-scan` | — | `top.lldwb.alistmediasync` | OpenAPI 扫描的包路径，仅扫描此包下的 Controller 与 DTO 注解。 |
| `springdoc.show-actuator` | — | `false` | 是否在 OpenAPI 文档中暴露 Actuator 端点。默认关闭。 |

> **访问控制**：`/v3/api-docs**` 与 `/swagger-ui**` 始终被 `AuthInterceptor` 放行（见 `AuthInterceptor.EXCLUDE_PATHS`），生产环境通过 `springdoc.*.enabled=false` 禁用端点本身实现访问控制。

## 6. 敏感项标记与生产建议

### 6.1 敏感配置项

以下配置项包含敏感信息，在日志输出与诊断包中均会被脱敏处理（替换为 `***REDACTED***`）：

| 配置路径 | 环境变量 | 脱敏位置 | 脱敏方式 |
|---|---|---|---|
| `app.auth.password` | `APP_AUTH_PASSWORD` | `diagnose.sh` 环境变量收集、日志输出 | `awk` 正则匹配 `password` 关键词 |
| `alist.token` | `ALIST_TOKEN` | `diagnose.sh` 环境变量收集、日志输出 | `awk` 正则匹配 `token` 关键词 |
| `alist.crypto-key`（代码读取） | `ALIST_CRYPTO_KEY` | `diagnose.sh` 环境变量收集 | `awk` 正则匹配 `cryptokey`/`crypto_key` 关键词 |

> 脱敏实现参见 `scripts/diagnose.sh`。

### 6.2 生产环境必设项

| 配置项 | 环境变量 | 建议值 | 原因 |
|---|---|---|---|
| `app.auth.password` | `APP_AUTH_PASSWORD` | 避免默认值 `admin123`，使用强密码 | 默认密码可被公开文档查询到，存在未授权访问风险。 |
| `alist.crypto-key` | `ALIST_CRYPTO_KEY` | `openssl rand -base64 32` 生成 | AES-256 加密密钥。**缺失时每次重启随机生成**，导致已加密的数据库字段（如 AList Token）永久不可解密。 |

> `ALIST_CRYPTO_KEY` 不在 `application.yaml` 中显式定义，由 `CryptoKeyEnvironmentPostProcessor` 从环境变量读取并注入。生产环境必须设置，否则数据将在重启后无法解密。

### 6.3 生产环境建议

| 配置项 | 建议值 | 原因 |
|---|---|---|
| `springdoc.api-docs.enabled` | `false` | 禁用 API 文档端点，避免未认证访问暴露 API 结构 |
| `springdoc.swagger-ui.enabled` | `false` | 禁用 Swagger UI，同上 |
| `LOGGING_LEVEL` | `WARN` | 生产环境应减少日志量，业务包 `top.lldwb.alistmediasync` 跟随全局级别 |
| `JAVA_OPTS` | 根据 `TRANSCODE_MAX_CONCURRENT` 调整 | 默认 `-Xmx256m` 仅支持轻量场景。转码并发越高，FFmpeg 子进程越多，需要更大的堆外内存上限 |
